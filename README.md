## 🔐 LOLcrypt Tool (Python)
This is a simple Python tool that lets you encrypt, decrypt, and brute-force decrypt messages using the Caesar Cipher, a classic substitution cipher.

## 💡 Features:
```
🔐 Encrypt messages with a shift key (1–25)

🔓 Decrypt using the known shift

🕵️‍♂️ Brute-force decrypt without knowing the key

✅ Supports uppercase, lowercase, and symbols
```

## ⚙️ How It Works:
```
Each letter is shifted by a fixed number (the key).

Brute-force mode tries all 25 possible shifts to crack the cipher.
```

## ▶️ Usage:
```
Run the script and choose:

[E] to Encrypt

[D] to Decrypt

[B] to Brute-force decrypt
